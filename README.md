# Terminal-Based Hangman Game (Python)

A fully interactive, terminal-based Hangman game written in pure Python. The game features interactive ASCII art representing the hangman's stages, dynamic clues, and strict input validations.

## 🚀 Key Features
* **Dynamic Clue Engine:** Pulls words from an internal dictionary along with their contextual hints (e.g., related to networking, virtualization, and systems).
* **Strict Input Validation:** Includes checks to prevent multi-character entries, non-alphabetic inputs, or repeated guesses from eating up attempts.
* **State Management:** Manages game flow dynamically through set operations to track guesses and remaining moves.

## 🎮 How to Play
1. Make sure you have Python installed on your system.
2. Run the script from your terminal:
   ```bash
   python hangman.py
